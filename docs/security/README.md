# Security pack

Security and compliance are 30 % of the score; this folder holds the evidence (spec 08, spec 12). Start with the self-assessment.

| Document | Content | Status at M17 |
|---|---|---|
| [SELF_ASSESSMENT.md](SELF_ASSESSMENT.md) | Permission tiers T0 to T4 with their verifying functions, signers and tests; invariants I1 to I19 with their tests; threat model; 30 known risks; coverage, Slither, dependency audit, GPL boundary | Written (M17); Chinese: [../zh-CN/SELF_ASSESSMENT.md](../zh-CN/SELF_ASSESSMENT.md) |
| [slither.md](slither.md) | Every Slither finding of the Base contracts explained; the vendored WeCross proxy triaged; the FISCO contracts analysed once | Re-run in M17; `make slither` is red because of the vendored proxy (D66) |
| [deps.md](deps.md) | `pnpm audit --prod` with a reachability assessment per advisory, pinning, gitleaks | Written (M17); upgrades pending |
| [tee-checklist.md](tee-checklist.md) | The TEE deployment checklist for agent-signer and soter-attester, with what the code enforces today | Results after the Phala deployment (Phase C) |
| [wecross.md](wecross.md) | Security notes on the WeCross transport: keys, silence, unguarded hub setters, router logs, network | Written (M12) |
| [gas.md](gas.md) | Gas of the first userOp, an agent payment, a refused op and a RefusalLog entry | Written (M3) |
| `redteam.md` | The red-team suite's results: each attack, expected and observed outcome, transaction hashes, "N attacks, 0 executed" | Generated by the suite in M16 |
| `pentest.md` | Pentest findings and fixes (web app, api, mcp and OAuth, mini program backend, WeChat callback, console) | Phase C |
